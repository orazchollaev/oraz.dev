## Overview
**Nuxt Feature Starter** is a template for projects that grow. Every feature lives under `app/features/` as a self-contained module.

## Structure
Each feature folder holds its own components, composables, stores, types, pages and locales, so a feature can be added or removed without touching the rest of the app.

```
app/features/blog/
  ├── components/
  ├── composables/
  ├── stores/
  ├── types/
  ├── pages/
  └── locales/
```
